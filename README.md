# 🚀 DevGuardian AI

DevGuardian AI is an autonomous multi-agent DevOps assistant that analyzes GitHub Actions CI/CD failures, diagnoses root causes using AI agents, recommends fixes, and automatically creates GitHub Pull Requests.

## 🎯 Project Goal

Build an AI-powered DevOps Engineer capable of:

- Monitoring GitHub Actions workflows
- Diagnosing CI/CD failures
- Inspecting Docker environments
- Generating intelligent fixes
- Creating GitHub Pull Requests
- Learning from previous incidents (RAG)

## 🛠 Tech Stack

- Python
- FastAPI
- LangGraph
- LangChain
- PostgreSQL
- Docker
- GitHub API
- SQLAlchemy
- Alembic
